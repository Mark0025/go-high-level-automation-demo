Go High Level Automation Demo

This demo project showcases automation, data hygiene, and workflow skills for the Go High Level CRM platform, using Node.js scripts and sample data.

Features

  • CSV Header Validation & Normalization
  • Bulk Contact Import & Data Hygiene
  • Phone Validation Workflow
  • AI-SMS Workflow Cloning & Adaptation
  • Zapier Webhook Simulation
  • Quarterly Data Purge

Project Workflow Overview

CSV File → Validation → Import & Normalization → Phone Validation →
Workflows (SMS, Zapier, Purge) → Logs/Reports

Key Automation Steps

1. CSV Header Validation

[Read CSV Header]
      ↓
[Header matches canonical?] → Yes → [Log: Header matches]
                        ↘ No → [Log: Mismatches]

2. Bulk Contact Import & Normalization

[Read CSV Rows] → [Normalize Data] → [Map Custom Fields/Tags]
      → [Simulate Import] → [Log Imported Contact]

3. Phone Validation Workflow

[Read Contact Row] → [Check Phone 1-3] → [Valid Mobile?]
      → Yes → [Tag: Mobile Valid] → [Log Result]
      → No  → [Tag: Invalid/Not Mobile] → [Log Result]

4. AI-SMS Workflow Cloning & Adaptation

[Read Campaign A Workflow] → [Clone Workflow]
      → [Adapt Messages for Campaign B]
      → [Track Replies at Master Level]
      → [Output New Workflow]

5. Zapier Webhook Simulation

[Contact Reaches Offer Sent Stage] → [Prepare Webhook Payload]
      → [Send to Direct-Mail Platform] → [Log Payload]

6. Quarterly Data Purge

[Read Contacts] → [Check Last Activity] → [Inactive Before Cutoff?]
      → Yes → [Archive/Delete Contact] → [Log Archived]
      → No  → [Keep Contact]

Script Descriptions

  • validate_csv.js: Checks if a CSV matches the canonical header, outputs mismatches.
  • import_contacts.js: Reads CSV, normalizes data, simulates import, maps custom fields/tags.
  • phone_validation.js: Validates phone numbers (using libphonenumber-js), tags contacts, outputs results.
  • clone_sms_workflow.js: Reads a JSON workflow, clones/adapts for a new campaign, tracks replies.
  • zapier_webhook.js: Simulates sending a webhook with dynamic variables for direct-mail integration.
  • data_purge.js: Filters contacts by last activity, simulates archiving/deleting.
